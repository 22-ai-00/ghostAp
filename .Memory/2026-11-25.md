# 2026-11-25 — Workflow HTML 与 Markdown 报告可读性重构

## 根因

1. `src/workflow_engine/reporting.py` 旧实现仅对 `project.result` 做单层 `json.loads()`，并将 `handoff`、`deliverables`、`verification`、`output` 等字段直接经 `_pretty_json()` 塞入带 `max-height: 600px` 的等宽 `<pre>` 滚动框（`.section-body`）；双层 JSON 转义字符串（如 `"output": "{\n ..."`）未被递归解包，Markdown 标题、管道表格（`|---|`）、列表和行内代码只能以纯文本显示。
2. Teamwork 产物在 `card_summary`、`handoff`、字符串化 `output` 与顶层 `verification` 间存在大量重复；当自动评审未通过（`accepted=false`）且已由综合器对照源码修正时，`verified_output` 初稿与修正后的 `deliverables` / `conclusion` 并列展示易产生矛盾；执行过程与原始调试 JSON 混排也削弱了首屏可读性。

## 改动摘要

1. **纯标准库 GFM Markdown-to-HTML 渲染器（`src/workflow_engine/report_markdown_html.py`）**
   - 仅使用 Python 标准库（`html`、`re`、`unicodedata`、`urllib.parse`）实现 `render_markdown_to_html(text)` 与 `looks_like_markdown(text)`。
   - 对全部不可信原始 HTML 标签与属性严格转义；链接 URL 仅允许 `http://`、`https://`、`mailto:`、`#anchor` 与无 scheme 相对路径（校验 HTML 实体解码与空白折叠形式，拒绝 `javascript:`、`data:`、`vbscript:`、`file:` 及 `//` 协议相对路径）。
   - 支持 ATX 标题（`h1.md-h1`..`h6.md-h6`）、多反引号/波浪线围栏代码块（`md-code-block`）、GFM 管道表格（`md-table-wrap`/`md-table`，支持 `\|` 转义、行内代码管道符、对齐及单元格内联格式）、引用与 5 类 GitHub Alerts（`md-quote`/`md-alert-*`）、嵌套列表与任务复选框（`md-list`/`md-task-list`）、分隔线、行内代码（`md-inline-code`）、粗体/斜体/删除线（保留 `foo_bar_baz` 与 `v1/videos*` 等标识符及路径通配符）。

2. **载荷递归解包与语义结构化（`src/workflow_engine/report_normalizer.py`）**
   - 新增冻结数据模型 `StructuredTable`、`NormalizedBlock`、`NormalizedSection`、`NormalizedAgentView`、`NormalizedWorkflowReport`。
   - 新增 `unwrap_nested_json(value, *, max_depth=4)` 递归解析 `{`/`[` JSON 字符串及完整 ```` ```json ```` / `~~~json` 围栏块；新增 `normalize_agent_output(raw_result)` 解析单次 Agent 输出并保留原始 `raw_text`。
   - 新增 `normalize_workflow_report(project)`：合并去重 `card_summary`、`handoff`、解包后 `output` 与 `verification`；将分组或扁平 `deliverables` 转为中文化表头 `StructuredTable`（如 `分类`/`入口与说明`/`源码依据`）；当 `accepted is False` 且存在 `synthesizer_reverification` 或 `deliverables` 时，将 `verified_output` 折叠隔离至「补充参考：评审阶段初稿（部分待修订）」并附警告提示；提取 `verdict`、`verdict_label`、`headline_conclusion` 并填充全部 `agent_views[(p_idx, a_idx)]`。

3. **离线 UX 预览与报告生成升级（`ux/workflow-report-preview.html`、`src/workflow_engine/reporting.py`）**
   - 依据 `AGENTS.md` UI 规则先行交付离线视觉与交互预览 `ux/workflow-report-preview.html`，并与生产输出保持一致。
   - 升级 `build_workflow_report_html()` 与 `build_workflow_report_markdown()`（完整保留 `WorkflowReportFiles`、`DEFAULT_WORKFLOW_CACHE_ROOT`、`write_workflow_report_files()` 等公开接口及既有回归契约）：新增 Hero 指标网格、执行结论横幅与 Agent Pool 芯片；吸顶工具栏支持全文/阶段/Agent 搜索与「主要阅读 / 附录原始数据」分类目录；主阅读区以 `md-table`、`md-prose`、`kv-grid`、`callout-card`、`semantic-list` 完整渲染（移除主区 `max-height: 600px` 等宽截断）；`执行过程` 为各 Agent 提供可折叠 `.agent-output-drawer` 与嵌套 `.agent-raw-drawer`；底部 `#appendix` 默认折叠保留补充参考、`原始结果 JSON`、`原始 Workflow 状态 JSON` 与 `完整 Markdown 源文本`；Markdown 报告同步输出可读 GFM 章节、管道表格、列表与 Alerts。

4. **回归测试与安全审计（`tests/test_workflow_report*.py`）**
