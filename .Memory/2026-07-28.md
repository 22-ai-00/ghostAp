## 子任务失败详情默认折叠

### 背景与根因

- 现场截图中的独立子任务失败卡把 `CardEvent.failed(error)` 的完整错误字符串作为 `_error` 文本块直接渲染。
- 当错误是 `formatted_output` JSON、pytest 输出或调用栈时，文本块会直接占满正文并触发多页卡片；用户必须滚过大量诊断信息才能看到终态。
- 错误内容没有丢失或传输失败，问题位于卡片信息层级：详细诊断与摘要处于同一默认展开层。

### 修改

- 新增 `src/card/render/error.py`，从完整错误中提取稳定、单行的失败摘要：
  - pytest 输出优先提取 `FAILED <test-id>`；
  - 长 JSON 或不可读首行退化为“任务返回了较长的错误信息”；
  - 摘要经过单行标签清洗和长度限制，避免 raw JSON 污染面板标题。
- `src/card/render/renderer.py` 对终态为 `failed` 的子任务 `_error` 文本块使用红色 `collapsible_panel`：
  - `expanded=false`，完整 JSON、测试输出与调用栈默认收起；
  - 面板标题常显简短摘要和“已收起”状态；
  - 过长错误仍按原分页预算切分，每一段都保持折叠，诊断内容不丢失。
- 新增 `ux/subtask-error-collapse.html`，固化“摘要常显、详情按需展开”的 UI 预览。
- 新增回归测试覆盖长 JSON + pytest + 调用栈，验证所有错误面板默认折叠、标题不泄漏 `formatted_output`、完整错误仍存在于折叠内容中。

### 验证

- TDD 红灯：新增定向测试修复前失败，未找到错误折叠面板。
- 定向绿灯：`1 passed`。
- 相关回归：`192 passed`。
- 扩展卡片与编程模式测试：`1154 passed`。
- `uv run ruff check src/card/render/error.py src/card/render/renderer.py tests/test_card_renderer.py`：通过。
- `uv run python -m src.main --validate`：通过。

### 发布与风险

- 修改只作用于独立子任务失败块；主任务错误卡和正常结果卡不改变。
- 已经发出的历史卡片不会自动重写；服务重启后新产生或后续更新的子任务失败卡使用新样式。
- 折叠只改变默认视觉状态，不减少飞书卡片 JSON 的有效载荷；极长错误仍可能分页，但每页详情均保持收起。

## Help 与 Workflow 帮助卡片格式优化

### 背景与根因

- `/help` 标题带内部版本号，正文顶部还有一整块“常用操作”按钮；这些快捷入口与 `/menu` 重复并挤占帮助内容的首屏空间。
- `/wf_help` 把带 `**`、反引号和项目符号的 Markdown 交给 `reply_text()`，飞书按普通文本渲染，因此格式标记直接暴露、层级不清晰。

### 修改

- `/help` 标题改为 `📖 GhostAP 使用帮助`，移除版本号、“常用操作”标题和全部快捷按钮；完整命令折叠分区、当前状态与底部提示保持不变。
- 删除只服务于帮助快捷区的 `_get_version()`、`_help_callback_button()` 和 `_build_help_quick_action_elements()`，快捷操作继续由 `/menu` 承担。
- `/wf_help` 改用标准 Schema 2.0 卡片：
  - turquoise 标题 `⚡ Workflow 使用帮助`；
  - 顶部展示简介和统一 `_node_version_required_text()` 运行要求；
  - 命令列表默认展开，执行流程和核心能力默认折叠；
  - 通过 `reply_card()` 发送，不再暴露未渲染 Markdown。
- 更新 `ux/card_preview.html`，同步展示精简后的 `/help` 与新的 `/wf_help` 卡片。
- 新增/更新回归测试，锁定无版本号、无快捷按钮、Workflow 卡片 Schema、分区展开状态和核心命令。

### 验证

- 扩大回归：`tests/test_card_builders.py tests/test_card_schema_contract.py tests/test_workflow_entry_help.py tests/test_system_interaction.py` → `79 passed`。

- `uv run python -m src.main --validate`：配置校验通过。
