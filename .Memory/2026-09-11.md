### 后端要点（src/agent_session/codex_cli.py，全新文件）

- argv 形态：`codex-w [-c model="x"] [-c model_reasoning_effort="e"] exec
  --json --skip-git-repo-check -C <cwd> [resume <thread_id>] <prompt>`。
- **关键 quirk（真实踩坑，非显而易见）**：所有 `-c key=value` 必须出现在
  `exec` 子命令**之前**；放在 exec 之后会导致 codex 解析 model metadata 失败、
  静默回退 ChatGPT 账号路由并返回 HTTP 400。测试专门断言每个 `-c` 的索引都
  小于 `exec` 索引。
- JSONL 事件：`thread.started` 回填 session_id（首条 prompt 后即 is_resumed），
  `item.completed` 且 `item.type=="agent_message"` 取文本，`error`/`turn.failed`
  判失败；空 stdout + rc0 正常返回 end_turn。
- effort SSOT 在 `src/acp/model_selection.py`：
  `CODEX_REASONING_EFFORT_ORDER=(none,minimal,low,medium,high,xhigh,max,ultra)`，
  复合持久化值 `model/effort`（split/compose_codex_model_selection），
  `default` model 哨兵省略 model override、default/空 effort 省略 effort override；
  CLI 无 ACP catalog，helper 静态合成"伪 default 模型 + effort 阶梯"矩阵免探测。
- 真实 CLI 分流只认 `is_cli_backend()` / `is_codex_cli_backend()`
  （`backend_resolver.py` SSOT）：`CLI_BACKEND_AGENTS={claude,claude_w,codex_w}`、
  `CODEX_CLI_BACKEND_AGENTS={codex_w}`。retry starter 的 codex 分支忽略注入的
  `cli_session_cls`、直接 import 具体 `SyncCodexCLISession`，测试须 patch 源模块。
